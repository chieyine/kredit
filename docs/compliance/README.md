# Compliance documentation

Store approved legal wording, provider approvals, DPIA material, retention
decisions, and regulatory-partner evidence here. Unapproved assumptions belong
in `docs/product/open-questions.md`, not in production behaviour.

The current technical data inventory is in
[`data-inventory.md`](data-inventory.md). It is a control register, not legal
advice; approved retention periods and lawful-basis decisions must be attached
before production launch.
